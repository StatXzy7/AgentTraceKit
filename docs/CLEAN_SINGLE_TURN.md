# 干净单轮执行与历史保留

默认生产协议使用一份冻结题面、固定模型/连接、冻结基线 SHA，以及每侧独立的配置目录、工作区和会话。收尾核对原轨迹中的真实用户消息及轮次，注入环境说明不冒充新用户轮次。

失败尝试留在 `evidence/<pair-id>/attempts/`，被替换工作区与旧评审分别保留。干净重跑从原完整 SHA 重建，不把两次会话拼成一条成功原件，不继续沿用旧视频/提交/评审绑定。显式续接另有策略和额外轮次记录，见 [恢复策略](COMPLETION_PROFILE.md)。

手动重跑开启新的有限预算；服务重启和自动重试保留当前尝试数与截止时间。旧失败不会被删掉，重跑成功也不能把历史叙述改为“首次成功”。

单轮检查是本框架的执行协议，不等于任何外部平台的语义质审、Hidden 评测或最终验收。
